# 法律依据池(通用合同审查)

本文件是合同审查中法律引用的**唯一来源**。所有审查报告中的法律引用必须来自本池,禁止凭记忆编造法律条文。

## 一、民法典核心条款

### 1.1 合同通则

| 条款 | 简称 | 内容摘要 |
|------|------|---------|
| 第7条 | 诚信原则 | 民事主体从事民事活动,应当遵循诚信原则,秉持诚实,恪守承诺 |
| 第142条 | 意思表示解释 | 有相对人的意思表示的解释,应当按照所使用的词句,结合相关条款、行为的性质和目的、习惯以及诚信原则,确定意思表示的含义 |
| 第465条 | 合同约束力 | 依法成立的合同,受法律保护 |
| 第466条 | 合同解释 | 当事人对合同条款的理解有争议的,应当依据本法第142条的规定,确定争议条款的含义 |
| 第490条 | 合同成立 | 当事人采用合同书形式订立合同的,自当事人均签名、盖章或者按指印时合同成立 |
| 第509条 | 全面履行 | 当事人应当按照约定全面履行自己的义务 |
| 第510条 | 合同补充 | 合同生效后,当事人就质量、价款或者报酬、履行地点等内容没有约定或者约定不明确的,可以协议补充 |
| 第511条 | 补充规则 | 当事人就有关合同内容约定不明确,依据前条规定仍不能确定的,适用规定 |

### 1.2 违约责任

| 条款 | 简称 | 内容摘要 |
|------|------|---------|
| 第577条 | 违约责任 | 当事人一方不履行合同义务或者履行合同义务不符合约定的,应当承担继续履行、采取补救措施或者赔偿损失等违约责任 |
| 第580条 | 履行不能 | 当事人一方不履行非金钱债务或者履行非金钱债务不符合约定的,对方可以请求履行,但有下列情形之一的除外 |
| 第584条 | 损害赔偿范围 | 损失赔偿额应当相当于因违约所造成的损失,包括合同履行后可以获得的利益;但不得超过违约一方订立合同时预见到或者应当预见到的因违约可能造成的损失 |
| 第585条 | 违约金 | 约定的违约金低于造成的损失的,人民法院或者仲裁机构可以根据当事人的请求予以增加;约定的违约金过分高于造成的损失的,可以予以适当减少 |
| 第588条 | 违约金与定金 | 当事人既约定违约金,又约定定金的,一方违约时,对方可以选择适用违约金或者定金条款 |
| 第589条 | 拒绝受领 | 债务人按照约定履行债务,债权人无正当理由拒绝受领的,债务人可以请求赔偿增加的费用 |
| 第590条 | 不可抗力 | 因不可抗力不能履行合同的,根据不可抗力的影响,部分或者全部免除责任 |

### 1.3 合同解除

| 条款 | 简称 | 内容摘要 |
|------|------|---------|
| 第562条 | 协商解除 | 当事人协商一致,可以解除合同 |
| 第563条 | 法定解除 | 有下列情形之一的,当事人可以解除合同:(1)因不可抗力致使不能实现合同目的;(2)在履行期限届满前,当事人一方明确表示或者以自己的行为表明不履行主要债务;(3)当事人一方迟延履行主要债务,经催告后在合理期限内仍未履行;(4)当事人一方迟延履行债务或者有其他违约行为致使不能实现合同目的 |
| 第566条 | 解除后果 | 合同解除后,尚未履行的,终止履行;已经履行的,根据履行情况和合同性质,当事人可以请求恢复原状或者采取其他补救措施,并有权请求赔偿损失 |

### 1.4 买卖合同

## 六、引用规范

### 6.1 引用格式

- 法律名称使用全称,如《中华人民共和国民法典》
- 首次引用使用全称,后续可用简称,如《民法典》
- 条款引用格式:第X条
- 款项引用格式:第X条第Y款
- 示例:《中华人民共和国民法典》第585条第2款

### 6.2 待核实标记

若审查中需引用本依据池之外的法律条款:
- 必须标注**"待核实"**
- 格式:《XXX》第X条(待核实)
- 并在审查报告中说明待核实原因
